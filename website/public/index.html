What does it do? Literally 3 things.

Over time Downloads fills up with invoices, screenshots, installers and zips. CleanDownloads cleans it up for you, safely.

1. It sorts

Looks at each loose file in Downloads and files it into the right folder: Documents, Images, Software, Code and more.

2. It shows you first

Run preview to see every planned move. Nothing happens until you say so.

3. It can undo

Changed your mind? Run undo and every file goes back where it started.

All the receipts.

Every feature in the repo, in plain words.

Auto categorization

13+ categories, hundreds of file types. Knows .tar.gz from .gz.

Zero-overwrite moves

Same filename? You get invoice (1).pdf. Backed by Win32 MoveFileExW, so nothing is replaced.

Preview and dry-run

cleandownloads preview or organize --dry-run shows the plan without touching a file.

Undo with proof

Every move is saved to a local SQLite history with a SHA-256 hash, so undo can check the file is untouched.

Download and lock protection

Skips .crdownload, .part, .tmp, .opdownload, .aria2 and files another app has locked.

Auto-clean on a schedule

Optional Windows Task Scheduler job: schedule --enable hourly.

Your rules

Custom categories, subfolders, ignored extensions and size limits in one JSON file.

100% local

No network requests, no telemetry. Filenames and contents never leave your PC.

One file, no setup

Ships as a standalone cleandownloads.exe. No Python needed.

Under the hood: 7 steps.

01 Scan

Root of Downloads only. Subfolders stay untouched.

02 Filter

Skip hidden, system, locked, in-progress and symlinked files.

03 Classify

Match extensions to classification rules.

04 Plan

Preview moves, number any duplicate names.

05 Move

Atomic Win32 move, zero overwrites.

06 Record

Paths, times and SHA-256 saved to history.db.

07 Undo

Verify the hash, restore the original spot.

Safe by design.

Your files never leave your machine. Here is what is guaranteed.

Zero deletion

No unlink, remove or purge code for user files anywhere in the core engine.

No overwrites

Collisions get renamed atomically by the operating system (e.g. report (1).pdf).

Path containment

Rejects .. traversal escapes and reserved Windows device names (CON, PRN, AUX, NUL).

Hash-checked undo

Checks SHA-256 signatures before undoing moves, ensuring only pristine files restore.

Fully offline

Zero analytics, zero telemetry, zero metadata sent over the network.

Known limitation

Files exclusively locked by another application cannot be moved until closed. They are logged and safely left alone.

Make it yours.

Settings live in %LOCALAPPDATA%\CleanDownloads\config.json.

downloads_dirFolder to clean. Default: your Windows Downloads directory.
recursiveScan subfolders? Default: false (root level only).
conflict_strategy"rename" adds (1), (2) automatically on duplicates.
ignored_extensionsIn-progress types (.crdownload, .tmp, .part) to always skip.
excluded_directoriesCategory folders ignored during the root scan.
default_fallback_folderWhere unknown extensions go. Default: "Other".
